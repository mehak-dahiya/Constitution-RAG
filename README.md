# Constitution-RAG
Offline Retrieval-Augmented Generation chatbot for the Constitution of India. Uses PyPDF for parsing, LangChain for chunking, BAAI/bge-small-en-v1.5 embeddings, FAISS for vector search, and a locally-run Llama 3.2 (3B) model via Ollama to generate grounded, context-aware answers — no internet or API keys needed.
